# 🌟 NEXUS AI Creators — Інтерактивна вітрина віртуальних блогерів

Сучасний Mobile-First веб-каталог цифрових AI-блогерів нового покоління з живим інтерактивом, Web Audio звуковими ефектами, плавним скролінгом та інтерактивними історіями.

---

## ✨ Основні можливості

- 🎭 **4 унікальні AI-особистості**:
  - **Alex Rivera** (@alex.neural) — AI Tech & Hardware Pioneer (чоловік)
  - **Mark Nomad** (@mark.nomad) — Extreme Travel & Discovery (чоловік)
  - **Elena Vance** (@elena.vance) — High Fashion & Editorial Aesthetics (жінка)
  - **Kira Vance** (@kira.longevity) — Longevity, Biohacking & Neuro-Fitness (жінка)
- 📱 **Інтерактивні Stories**:
  - Стрічка історій у стилі Instagram / Telegram з неоновими статусами «New Story».
  - Повнорозмірний перегляд із 5-секундним автопрогресом, паузою та навігацією.
- 💬 **Симуляція AI-діалогу**:
  - Індивідуальні системні промпти, швидкі підказки (chips), індикатор набору тексту та миттєві відповіді.
- 🔊 **Звукові ефекти (Web Audio API)**:
  - М'який приємний «клік / поп» при перемиканні фільтрів та відкритті карток.
  - Мелодійний відгук на лайки з анімацією святкового конфеті.
  - Без зовнішніх mp3-файлів (100% чиста програмна синтезація).
- 🔍 **Миттєвий пошук та фільтрація**:
  - Живий пошук за ім'ям, тегами (#AI, #Longevity) та ключовими словами без перезавантаження.
- 🌊 **Плавна інерційна прокрутка**:
  - Інтегровано Lenis Smooth Scroll з повною підтримкою мобільних пристроїв та модальних вікон.
- 🌐 **Повна локалізація та SEO**:
  - 100% українська мова інтерфейсу.
  - Розширені OpenGraph та Twitter Cards мета-теги для красивого прев'ю у соцмережах та месенджерах (Telegram, Slack, LinkedIn).

## 🛠 Технологічний стек

- **Frontend**: React 18, TypeScript, Vite
- **Стилізація**: Tailwind CSS, CSS Animations
- **Іконки**: Lucide React
- **Анімації та ефекти**: Canvas-Confetti, Lenis Scroll
- **Звук**: Web Audio API Synthesizer

## 🚀 Швидкий запуск локально

```bash
# 1. Клонувати репозиторій
git clone https://github.com/Andzat/Blogers.git
cd Blogers

# 2. Встановити залежності
npm install

# 3. Запустити локальний сервер розробки
npm run dev
```

Локальний сервер буде доступний за адресою: `http://localhost:3000/`.

---

## 📦 Збірка для продакшну

```bash
npm run build
```

Зібрані оптимізовані файли будуть створені в папці `dist/`.
